# youtube-safe Server — Implementierungsplan (Plan 1 von 4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Der komplette Server aus der Spec (`docs/superpowers/specs/2026-11-08-youtube-safe-design.md`): API für Eltern- und Kinder-App, Entscheidungslogik, Benachrichtigungen (ntfy + Mail), Hintergrundjobs, Docker-Deployment.

**Architecture:** FastAPI + SQLAlchemy 2 + Alembic, MariaDB im Betrieb, SQLite in den Tests — Aufbau und Stil wie `openVerba`. Reine Logik (Entscheidung, Zeit) liegt in eigenen Modulen ohne Datenbank; Router sind dünn, Seiteneffekte (Push, Mail) laufen über `app/events.py`, das wiederum nur `app/notify.py` als Transport benutzt. Die Entscheidungslogik wird gegen `shared/gate-cases.json` getestet, die später auch die Kotlin-Implementierung prüft.

**Tech Stack:** Python 3.11+ (Pi: 3.11, Image: 3.12), FastAPI 0.115, SQLAlchemy 2.0, Alembic 1.14, PyMySQL, bcrypt, httpx, pytest; Docker Compose mit MariaDB 11 und ntfy.

**Die vier Pläne:**
1. **Server** (dieser Plan)
2. Android `core` + Eltern-App
3. Kinder-App
4. CI-Release-Pipeline (täglicher Extractor-Check, Live-Selbsttest, Signieren, `/updates/`) und Self-Update

## Festlegungen, die über die Spec hinausgehen

Beim Ausplanen nötig geworden; bitte beim Review mitprüfen:

1. **Eltern-Login per E-Mail + Passwort**, Ergebnis ist ein zufälliges Bearer-Token (Tabelle `parent_token`, nur der SHA-256-Hash wird gespeichert). Gilt bis zum Logout.
2. **ntfy-Zugriff:** Topics sind 32 Zufallszeichen (`yts-<hex>`) und damit das Geheimnis; **schreiben darf nur der Server** (eigener ntfy-Benutzer mit Token), lesen darf jeder, der den Topic-Namen kennt (`auth-default-access: read-only`). Pro-Gerät-Benutzer in ntfy wären deutlich aufwendiger, ohne realen Sicherheitsgewinn — Push-Nachrichten enthalten nur kurze Texte und IDs.
3. **Kanal-Anfrage merkt sich das Ursprungsvideo** (`source_video_id`, `source_video_title`), damit „nur dieses Video freigeben“ möglich ist.
4. **Ablehnen einer früher freigegebenen Anfrage** löscht die passende `allow`-Regel (für das Kind, bei Bereich „alle“ auch die globale).
5. **Statistik-Tage** werden in `Europe/Berlin` gerechnet (`YTS_TIMEZONE`).
6. **Störungsmeldungen** gehen höchstens alle 6 Stunden pro Kind an die Eltern.
7. Eindeutigkeit von Regeln (`child_id`, `target_type`, `target_id`) wird **im Code** sichergestellt: MariaDB und SQLite behandeln `NULL` in Unique-Constraints als verschieden, die globalen Regeln wären sonst nicht geschützt.

```python
"""Entscheidungslogik: darf ein Kind ein Video sehen?

Reine Funktion ohne Datenbank. Dieselbe Logik steckt in der App (Modul core); beide
Seiten werden gegen shared/gate-cases.json getestet, damit sie nie auseinanderlaufen.

Reihenfolge (erste zutreffende Stufe gewinnt):
1. Belohnungsmodus mit „auch Gesperrtes“   -> erlaubt
2./3. Video-Regel (block / allow)
4./5. Kanal-Regel (block / allow)
6. Belohnungsmodus                          -> erlaubt
7. sonst                                    -> gesperrt
Innerhalb einer Stufe schlägt die Regel des Kindes die Regel für alle Kinder.
"""

from __future__ import annotations

from collections.abc import Iterable
from dataclasses import dataclass


@dataclass(frozen=True)
class RuleView:
    child_id: int | None
    target_type: str
    target_id: str
    effect: str


@dataclass(frozen=True)
class Decision:
    allowed: bool
    reason: str


def _effective_effect(
    rules: Iterable[RuleView], child_id: int, target_type: str, target_id: str
) -> str | None:
    specific: RuleView | None = None
    general: RuleView | None = None
    for rule in rules:
        if rule.target_type != target_type or rule.target_id != target_id:
            continue
        if rule.child_id is None:
            general = rule
        elif rule.child_id == child_id:
            specific = rule
    chosen = specific or general
    return chosen.effect if chosen else None


def decide(
    rules: Iterable[RuleView],
    *,
    child_id: int,
    video_id: str,
    channel_id: str,
    reward_active: bool,
    reward_includes_blocked: bool,
) -> Decision:
    rules = list(rules)
    if reward_active and reward_includes_blocked:
        return Decision(True, "reward_all")

    video = _effective_effect(rules, child_id, "video", video_id)
    if video == "block":
        return Decision(False, "video_block")
    if video == "allow":
        return Decision(True, "video_allow")

    channel = _effective_effect(rules, child_id, "channel", channel_id)
    if channel == "block":
        return Decision(False, "channel_block")
    if channel == "allow":
        return Decision(True, "channel_allow")

    if reward_active:
        return Decision(True, "reward")
    return Decision(False, "default")
```

```python
"""Konfiguration aus der Umgebung.

Kein anderes Modul liest direkt aus os.environ.
"""

from __future__ import annotations

from functools import lru_cache

from pydantic import Field, field_validator
from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file=".env", extra="ignore")

    # --- Anwendung ---
    base_url: str = Field(default="http://localhost:8080", alias="YTS_BASE_URL")
    timezone: str = Field(default="Europe/Berlin", alias="YTS_TIMEZONE")
    jobs_enabled: bool = Field(default=True, alias="YTS_JOBS_ENABLED")
    updates_dir: str = Field(default="/srv/updates", alias="YTS_UPDATES_DIR")

    # --- Erster Elternteil (nur, solange es noch keinen gibt) ---
    bootstrap_parent_name: str = Field(default="", alias="YTS_PARENT_NAME")
    bootstrap_parent_email: str = Field(default="", alias="YTS_PARENT_EMAIL")
    bootstrap_parent_password: str = Field(default="", alias="YTS_PARENT_PASSWORD")

    # --- Datenbank ---
    db_host: str = Field(default="db", alias="DB_HOST")
    db_port: int = Field(default=3306, alias="DB_PORT")
    db_name: str = Field(default="youtube_safe", alias="MARIADB_DATABASE")
    db_user: str = Field(default="youtube_safe", alias="MARIADB_USER")
    db_password: str = Field(default="", alias="MARIADB_PASSWORD")
    # Vollständige URL; überschreibt die Einzelwerte (Tests laufen gegen SQLite).
    database_url_override: str = Field(default="", alias="DATABASE_URL")

    # --- Mail (optional) ---
    smtp_host: str = Field(default="", alias="SMTP_HOST")
    smtp_port: int = Field(default=587, alias="SMTP_PORT")
    smtp_user: str = Field(default="", alias="SMTP_USER")
    smtp_password: str = Field(default="", alias="SMTP_PASSWORD")
    smtp_from: str = Field(default="", alias="SMTP_FROM")
    smtp_starttls: bool = Field(default=True, alias="SMTP_STARTTLS")

    # --- Push über ntfy (optional) ---
    # ntfy_url: wohin der Server veröffentlicht (intern, z. B. http://ntfy)
    # ntfy_public_url: womit sich die Apps verbinden (über NPM, https)
    ntfy_url: str = Field(default="", alias="NTFY_URL")
    ntfy_public_url: str = Field(default="", alias="NTFY_PUBLIC_URL")
    ntfy_token: str = Field(default="", alias="NTFY_TOKEN")

    @field_validator("base_url", "ntfy_url", "ntfy_public_url")
    @classmethod
    def _strip_trailing_slash(cls, value: str) -> str:
        return value.rstrip("/")

    @property
    def database_url(self) -> str:
        if self.database_url_override:
            return self.database_url_override
        return (
            f"mysql+pymysql://{self.db_user}:{self.db_password}"
            f"@{self.db_host}:{self.db_port}/{self.db_name}?charset=utf8mb4"
        )

    @property
    def mail_enabled(self) -> bool:
        return bool(self.smtp_host)

    @property
    def push_enabled(self) -> bool:
        return bool(self.ntfy_url)


@lru_cache
def get_settings() -> Settings:
    return Settings()
```

```python
"""Zeit an einer Stelle.

Die Datenbank speichert naive UTC-Zeitpunkte. Alle Module rufen clock.now() über das
Modul auf (nicht per from-Import), damit Tests die Uhr austauschen können.
"""

from __future__ import annotations

from datetime import datetime, timezone


def now() -> datetime:
    return datetime.now(timezone.utc).replace(tzinfo=None)


def to_naive_utc(value: datetime) -> datetime:
    if value.tzinfo is None:
        return value
    return value.astimezone(timezone.utc).replace(tzinfo=None)
```

```python
"""Engine und Session-Factory."""

from __future__ import annotations

from collections.abc import Iterator

from sqlalchemy import create_engine
from sqlalchemy.orm import DeclarativeBase, Session, sessionmaker

from app.config import get_settings


class Base(DeclarativeBase):
    pass


def _create_engine():
    url = get_settings().database_url
    kwargs: dict = {"pool_pre_ping": True, "future": True}
    if url.startswith("sqlite"):
        # In-Memory-SQLite der Tests muss über Threads hinweg dieselbe Verbindung sehen.
        from sqlalchemy.pool import StaticPool

        kwargs["connect_args"] = {"check_same_thread": False}
        kwargs["poolclass"] = StaticPool
    else:
        kwargs["pool_recycle"] = 3600
    return create_engine(url, **kwargs)


engine = _create_engine()
SessionLocal = sessionmaker(bind=engine, autoflush=False, expire_on_commit=False)


def get_session() -> Iterator[Session]:
    """FastAPI-Dependency: eine Session pro Request."""
    session = SessionLocal()
    try:
        yield session
    finally:
        session.close()
```

```python
"""Passwörter, Zufallstokens, Kopplungscodes und ntfy-Topics."""

from __future__ import annotations

import base64
import hashlib
import secrets

import bcrypt

# Ohne 0/O und 1/I, damit sich der Code notfalls auch abtippen lässt.
PAIRING_ALPHABET = "ABCDEFGHJKLMNPQRSTUVWXYZ23456789"


def _prepare(password: str) -> bytes:
    """bcrypt verarbeitet nur 72 Byte; vorher hashen statt still kürzen."""
    digest = hashlib.sha256(password.encode("utf-8")).digest()
    return base64.b64encode(digest)


def hash_password(password: str) -> str:
    return bcrypt.hashpw(_prepare(password), bcrypt.gensalt()).decode("ascii")


def verify_password(password: str, password_hash: str) -> bool:
    try:
        return bcrypt.checkpw(_prepare(password), password_hash.encode("ascii"))
    except (ValueError, TypeError):
        return False


def new_token() -> str:
```

```python
    session: Session = Depends(get_session),
) -> ParentToken:
    if credentials is None:
        raise _unauthorized()
    token = session.scalar(
        select(ParentToken).where(ParentToken.token_hash == hash_token(credentials.credentials))

    if token is None:
        raise _unauthorized()
    token.last_used_at = clock.now()

    session: Session = Depends(get_session),
) -> Parent:

    if parent is None:

    session: Session = Depends(get_session),
) -> Device:

        raise _unauthorized()
    device = session.scalar(
        select(Device).where(
            Device.token_hash == hash_token(credentials.credentials),
            Device.unpaired_at.is_(None),
        )
    )
    if device is None:
        raise _unauthorized()
    device.last_seen = clock.now()
    device.stale_notified_at = None
```

```python
"""Transport für Benachrichtigungen: ntfy-Push und Mail-Outbox.

Wer was bekommt, entscheidet app/events.py. Fehler im Transport werden protokolliert,
aber nie hochgereicht — eine Freigabe darf nicht daran scheitern, dass ntfy oder der
Mailserver gerade weg ist.
"""

from __future__ import annotations

import logging
import smtplib
from collections.abc import Sequence
from datetime import timedelta
from email.message import EmailMessage

import httpx
from sqlalchemy import select
from sqlalchemy.orm import Session

from app import clock
from app.config import get_settings
from app.models import MailOutbox

log = logging.getLogger(__name__)

# Wartezeiten nach dem 1., 2. und 3. Fehlversuch; nach dem 4. wird aufgegeben.
RETRY_DELAYS = (timedelta(minutes=5), timedelta(minutes=15), timedelta(minutes=60))


# --- Push ------------------------------------------------------------------------


def _send_push_real(
    topic: str, title: str, message: str, *, tags: Sequence[str] = (), priority: int = 3
) -> bool:
    settings = get_settings()
    if not settings.push_enabled or not topic:
        return False
    payload = {
        "topic": topic,
        "title": title,
        "message": message,
        "tags": list(tags),
        "priority": priority,
    }
    headers = {"Authorization": f"Bearer {settings.ntfy_token}"} if settings.ntfy_token else {}
    try:
        response = httpx.post(settings.ntfy_url, json=payload, headers=headers, timeout=10)
        response.raise_for_status()
    except httpx.HTTPError as exc:
        log.warning("Push an %s fehlgeschlagen: %s", topic, exc)
        return False
    return True


# Tests ersetzen send_push; der echte Weg bleibt über _send_push_real prüfbar.
send_push = _send_push_real


# --- Mail ------------------------------------------------------------------------


def mail_enabled() -> bool:
    return get_settings().mail_enabled


def queue_mail(session: Session, to_address: str, subject: str, body: str) -> None:
    """Legt eine Mail in die Outbox. Commit macht der Aufrufer."""
    if not mail_enabled() or not to_address:
        return
    session.add(
        MailOutbox(
            to_address=to_address,
            subject=subject,
            body=body,
            attempts=0,
            next_attempt_at=clock.now(),
            failed=False,
            last_error="",
        )
    )


def _smtp_send(to_address: str, subject: str, body: str) -> None:
    settings = get_settings()
    message = EmailMessage()
    message["Subject"] = subject
    message["From"] = settings.smtp_from or f"youtube-safe@{settings.smtp_host}"
    message["To"] = to_address
    message.set_content(body)
    with smtplib.SMTP(settings.smtp_host, settings.smtp_port, timeout=15) as smtp:
        if settings.smtp_starttls:
            smtp.starttls()
        if settings.smtp_user:
            smtp.login(settings.smtp_user, settings.smtp_password)
        smtp.send_message(message)


def process_mail_outbox(session: Session) -> int:
    """Verschickt alle fälligen Mails. Gibt die Zahl der erfolgreich versandten zurück."""
    if not mail_enabled():
        return 0
    now = clock.now()
    due = session.scalars(
        select(MailOutbox).where(
            MailOutbox.sent_at.is_(None),
            MailOutbox.failed.is_(False),
            MailOutbox.next_attempt_at <= now,
        )
    ).all()
    sent = 0
    for mail in due:
        try:
            _smtp_send(mail.to_address, mail.subject, mail.body)
        except Exception as exc:  # noqa: BLE001 - jeder SMTP-Fehler zählt als Fehlversuch
            mail.attempts += 1
            mail.last_error = str(exc)[:2000]
            if mail.attempts > len(RETRY_DELAYS):
                mail.failed = True
                log.error("Mail an %s endgültig gescheitert: %s", mail.to_address, exc)
            else:
                mail.next_attempt_at = now + RETRY_DELAYS[mail.attempts - 1]
                log.warning("Mail an %s gescheitert (Versuch %d): %s",
                            mail.to_address, mail.attempts, exc)
        else:
            mail.attempts += 1
            mail.sent_at = now
            sent += 1
    session.commit()
    return sent
```

`server/app/events.py`:
```python
"""Fachliche Benachrichtigungen: wer bekommt bei welchem Ereignis was.

Push-Tags, auf die die Apps reagieren:
- "sync"            Kind: Regeln/Einstellungen neu laden (ohne sichtbare Meldung)
- "request:<id>"    Eltern: neue Anfrage (App baut daraus die Knöpfe Freigeben/Ablehnen)
- "decision"        Kind: Entscheidung über eine Anfrage
- "reward"          Kind: Belohnungsmodus gestartet/beendet
- "info"            Eltern: reine Information
- "alert"           Eltern: Störung, Gerät meldet sich nicht

Mails werden nur in die Outbox gelegt; Commit macht der Aufrufer.
"""

from __future__ import annotations

from sqlalchemy import select
from sqlalchemy.orm import Session

from app import notify
from app.models import Child, ContentRequest, Device, Parent

KIND_LABEL = {"video": "Video", "channel": "Kanal"}


def _parents(session: Session) -> list[Parent]:
    return list(session.scalars(select(Parent).order_by(Parent.id)))


def sync_child(child: Child) -> None:
    notify.send_push(child.ntfy_topic, "sync", "sync", tags=("sync",), priority=1)


def sync_all_children(session: Session) -> None:
    for child in session.scalars(select(Child)):
        sync_child(child)


def request_created(session: Session, request: ContentRequest, child: Child) -> None:
    label = KIND_LABEL[request.target_type]
    title = f"{child.name} bittet um Freigabe"
    message = f"{label}: {request.title or request.target_id}"
    if request.channel_name and request.target_type == "video":
        message += f" ({request.channel_name})"
    if request.child_message:
        message += f"\n„{request.child_message}“"
    for parent in _parents(session):
        notify.send_push(parent.ntfy_topic, title, message, tags=(f"request:{request.id}",), priority=4)
        if parent.mail_new_request:
            notify.queue_mail(
                session,
                parent.email,
                f"youtube-safe: {title}",
                f"{message}\n\nLink: {request.url}\n"
                + (f"Vorschaubild: {request.thumbnail_url}\n" if request.thumbnail_url else "")
                + "\nEntscheiden kannst du in der Eltern-App.\n",
            )


def decision_made(
    session: Session, request: ContentRequest, child: Child, by: Parent, *, all_children: bool
) -> None:
    approved = request.status == "approved"
    label = KIND_LABEL[request.target_type]
    name = request.title or request.target_id
    if approved:
        kid_title = "Freigegeben 🎉"
        kid_message = f"{label}: {name}"
    else:
        kid_title = "Leider abgelehnt"
        kid_message = f"{label}: {name}" + (f"\nGrund: {request.reason}" if request.reason else "")
    notify.send_push(child.ntfy_topic, kid_title, kid_message, tags=("decision",))
    if all_children:
        sync_all_children(session)
    else:
        sync_child(child)

    verb = "freigegeben" if approved else "abgelehnt"
    for parent in _parents(session):
        if parent.id == by.id:
            continue
        notify.send_push(
            parent.ntfy_topic,
            f"{by.name} hat {verb}",
            f"{child.name}: {label} {name}",
            tags=("info", f"decided:{request.id}"),
            priority=2,
        )


def rules_changed(session: Session, child_id: int | None) -> None:
    if child_id is None:
        sync_all_children(session)
    else:
        child = session.get(Child, child_id)
        if child is not None:
            sync_child(child)


def reward_started(child: Child, until_text: str) -> None:
    notify.send_push(child.ntfy_topic, "Belohnungsmodus aktiv 🎉", f"Alles frei bis {until_text}",
                     tags=("reward", "sync"))


def reward_stopped(child: Child) -> None:
```

```python
def find_rule(session: Session, child_id: int | None, target_type: str, target_id: str) -> Rule | None:
    child_clause = Rule.child_id.is_(None) if child_id is None else Rule.child_id == child_id
    return session.scalar(
        select(Rule).where(child_clause, Rule.target_type == target_type, Rule.target_id == target_id)
    )


def upsert_rule(
    session: Session,
    *,
    child_id: int | None,
    target_type: str,
    target_id: str,
    effect: str,
    title: str = "",
    channel_name: str = "",
    note: str | None = None,
    parent_id: int | None = None,
) -> Rule:
    """Legt die Regel an oder ändert die bestehende für dasselbe Ziel. Commit macht der Aufrufer.

    Leere Titel/Kanalnamen überschreiben vorhandene Werte nicht.
    """
    now = clock.now()
    rule = find_rule(session, child_id, target_type, target_id)
    if rule is None:
        rule = Rule(
            child_id=child_id,
            target_type=target_type,
            target_id=target_id,
            title=title,
            channel_name=channel_name,
            effect=effect,
            note=note or "",
            created_by=parent_id,
            created_at=now,
            updated_at=now,
        )
        session.add(rule)
        session.flush()
        return rule
    rule.effect = effect
    if title:
        rule.title = title
    if channel_name:
        rule.channel_name = channel_name
    if note is not None:
        rule.note = note
    rule.updated_at = now
    session.flush()
    return rule
```

```python
    since: UtcIn | None = None,

    limit: int = 200,

    # Der Parameter heißt wie in der API „status“; fastapi.status wird hier deshalb nicht importiert.

    if request is None:
        raise HTTPException(404, "Anfrage nicht gefunden")

@router.post("/{request_id}/decision", response_model=RequestOut)
def decide_request(
    request_id: int,
    data: DecisionIn,
    parent: Parent = Depends(current_parent),
    session: Session = Depends(get_session),
) -> RequestOut:
    request = _get_or_404(session, request_id)
    child = session.get(Child, request.child_id)
    rule_child_id = None if data.scope == "all" else request.child_id

    if data.action == "approve":
        upsert_rule(session, child_id=rule_child_id, target_type=request.target_type,
                    target_id=request.target_id, effect=EFFECT_ALLOW, title=request.title,
                    channel_name=request.channel_name, parent_id=parent.id)
        request.status = STATUS_APPROVED
    elif data.action == "approve_video_only":
        if request.target_type != "channel" or not request.source_video_id:
            raise HTTPException(400, "Zu dieser Anfrage gibt es kein einzelnes Video")
        upsert_rule(session, child_id=rule_child_id, target_type="video",
                    target_id=request.source_video_id, effect=EFFECT_ALLOW,
                    title=request.source_video_title, channel_name=request.channel_name,
                    parent_id=parent.id)
        request.status = STATUS_APPROVED
    elif data.action == "reject":
        # Eine frühere Freigabe zu genau diesem Ziel zurücknehmen.
        scopes = [request.child_id] + ([None] if data.scope == "all" else [])
        for scope in scopes:
            existing = find_rule(session, scope, request.target_type, request.target_id)
            if existing is not None and existing.effect == EFFECT_ALLOW:
                session.delete(existing)
        request.status = STATUS_REJECTED
    else:  # reject_and_block
        upsert_rule(session, child_id=rule_child_id, target_type=request.target_type,
                    target_id=request.target_id, effect=EFFECT_BLOCK, title=request.title,
                    channel_name=request.channel_name, parent_id=parent.id)
        request.status = STATUS_REJECTED

    request.decided_by = parent.id
    request.decided_at = clock.now()
    request.reason = data.reason.strip()
    session.commit()
    events.decision_made(session, request, child, parent, all_children=data.scope == "all")
    return request_out(session, request)
```

```python
"""Belohnungsmodus — immer zeitlich begrenzt."""

from __future__ import annotations

from datetime import datetime, timedelta, timezone
from zoneinfo import ZoneInfo

from fastapi import APIRouter, Depends, HTTPException
from sqlalchemy.orm import Session

from app import clock, events
from app.config import get_settings
from app.db import get_session
from app.deps import current_parent, get_child_or_404
from app.models import Parent
from app.routers.parent_children import child_out
from app.schemas import MAX_REWARD_MINUTES, ChildOut, RewardIn

router = APIRouter(prefix="/parent/children", tags=["parent"])


def _local_text(utc_value: datetime) -> str:
    local = utc_value.replace(tzinfo=timezone.utc).astimezone(ZoneInfo(get_settings().timezone))
    return local.strftime("%d.%m. %H:%M")


@router.post("/{child_id}/reward", response_model=ChildOut)
def start_reward(
    child_id: int,
    data: RewardIn,
    _: Parent = Depends(current_parent),
    session: Session = Depends(get_session),
) -> ChildOut:
    child = get_child_or_404(session, child_id)
    now = clock.now()
    until = now + timedelta(minutes=data.minutes) if data.minutes is not None else data.until
    if until <= now:
        raise HTTPException(400, "Das Ende muss in der Zukunft liegen")
    if until - now > timedelta(minutes=MAX_REWARD_MINUTES):
        raise HTTPException(400, "Höchstens 30 Tage am Stück")
    child.reward_until = until
    child.reward_includes_blocked = data.include_blocked
    child.reward_expiry_notified = False
    session.commit()
    events.reward_started(child, _local_text(until))
    return child_out(child)


@router.delete("/{child_id}/reward", response_model=ChildOut)
def stop_reward(
    child_id: int, _: Parent = Depends(current_parent), session: Session = Depends(get_session)
) -> ChildOut:
    child = get_child_or_404(session, child_id)
    child.reward_until = None
    child.reward_includes_blocked = False
    child.reward_expiry_notified = True
    session.commit()
    events.reward_stopped(child)
    return child_out(child)
```

```python
"""Verlauf und Statistik pro Kind."""

from __future__ import annotations

from collections import defaultdict
from datetime import date, datetime, time, timedelta, timezone
from zoneinfo import ZoneInfo

from fastapi import APIRouter, Depends
from sqlalchemy import select
from sqlalchemy.orm import Session

from app import clock
from app.config import get_settings
from app.db import get_session
from app.deps import current_parent, get_child_or_404
from app.gate import decide
from app.models import Parent, WatchSession
from app.rules import as_views, rules_for_child
from app.schemas import ChannelStat, DayStat, HistoryEntryOut, StatsOut, UtcIn

router = APIRouter(prefix="/parent/children", tags=["parent"])


@router.get("/{child_id}/history", response_model=list[HistoryEntryOut])
def history(
    child_id: int,
    limit: int = 50,
    before: UtcIn | None = None,
    _: Parent = Depends(current_parent),
    session: Session = Depends(get_session),
) -> list[HistoryEntryOut]:
    child = get_child_or_404(session, child_id)
    query = (
        select(WatchSession)
        .where(WatchSession.child_id == child_id)
        .order_by(WatchSession.started_at.desc(), WatchSession.id.desc())
        .limit(max(1, min(limit, 200)))
    )
    if before is not None:
        query = query.where(WatchSession.started_at < before)
    views = as_views(rules_for_child(session, child_id))
    reward_active = child.reward_active(clock.now())
    result = []
    for item in session.scalars(query):
        decision = decide(
            views,
            child_id=child_id,
            video_id=item.video_id,
            channel_id=item.channel_id,
            reward_active=reward_active,
            reward_includes_blocked=child.reward_includes_blocked,
        )
        result.append(
            HistoryEntryOut(
                id=item.id,
                video_id=item.video_id,
                channel_id=item.channel_id,
                title=item.title,
                channel_name=item.channel_name,
                started_at=item.started_at,
                played_seconds=item.played_seconds,
                in_reward_mode=item.in_reward_mode,
                allowed_now=decision.allowed,
                reason_now=decision.reason,
            )
        )
    return result


def _local_day(value: datetime, zone: ZoneInfo) -> date:
    return value.replace(tzinfo=timezone.utc).astimezone(zone).date()


@router.get("/{child_id}/stats", response_model=StatsOut)
def stats(
    child_id: int,
    days: int = 7,
    _: Parent = Depends(current_parent),
    session: Session = Depends(get_session),
) -> StatsOut:
    get_child_or_404(session, child_id)
    days = max(1, min(days, 90))
    zone = ZoneInfo(get_settings().timezone)
    today = _local_day(clock.now(), zone)
    first_day = today - timedelta(days=days - 1)
    start_utc = (
        datetime.combine(first_day, time.min, tzinfo=zone).astimezone(timezone.utc).replace(tzinfo=None)
    )
    sessions = session.scalars(
        select(WatchSession).where(
            WatchSession.child_id == child_id, WatchSession.started_at >= start_utc
        )
    ).all()

    per_day: dict[date, list[int]] = {first_day + timedelta(days=i): [0, 0] for i in range(days)}
    per_channel: dict[str, list] = defaultdict(lambda: ["", 0])
    for item in sessions:
        day = _local_day(item.started_at, zone)
        if day not in per_day:
            continue
        per_day[day][0] += item.played_seconds
        if item.in_reward_mode:
            per_day[day][1] += item.played_seconds
        channel = per_channel[item.channel_id]
        channel[0] = channel[0] or item.channel_name
        channel[1] += item.played_seconds

    day_stats = [
        DayStat(date=d.isoformat(), seconds=v[0], reward_seconds=v[1]) for d, v in sorted(per_day.items())
    ]
    top = sorted(per_channel.items(), key=lambda kv: kv[1][1], reverse=True)[:10]
    return StatsOut(
        days=day_stats,
        top_channels=[ChannelStat(channel_id=cid, channel_name=v[0], seconds=v[1]) for cid, v in top],
        total_seconds=sum(d.seconds for d in day_stats),
        reward_seconds=sum(d.reward_seconds for d in day_stats),
    )
```

```python
"""Periodische Aufgaben: Mail-Outbox, Ende des Belohnungsmodus, stumme Geräte."""

from __future__ import annotations

import asyncio
import logging
from datetime import timedelta

from sqlalchemy import select
from sqlalchemy.orm import Session

from app import clock, events, notify
from app.db import SessionLocal
from app.models import Child, Device

log = logging.getLogger(__name__)

INTERVAL_SECONDS = 60
STALE_AFTER = timedelta(hours=24)


def run_periodic(session: Session) -> None:
    now = clock.now()
    notify.process_mail_outbox(session)

    expired = session.scalars(
        select(Child).where(
            Child.reward_until.is_not(None),
            Child.reward_until <= now,
            Child.reward_expiry_notified.is_(False),
        )
    ).all()
    for child in expired:
        child.reward_expiry_notified = True
        events.reward_expired(session, child)

    stale = session.scalars(
        select(Device).where(
            Device.unpaired_at.is_(None),
            Device.last_seen < now - STALE_AFTER,
            Device.stale_notified_at.is_(None),
        )
    ).all()
    for device in stale:
        device.stale_notified_at = now
        events.device_stale(session, device, session.get(Child, device.child_id))

    session.commit()


def _run_once() -> None:
    with SessionLocal() as session:
        run_periodic(session)


async def periodic_loop() -> None:
    while True:
        try:
            await asyncio.to_thread(_run_once)
        except Exception:  # noqa: BLE001 - ein Fehler darf die Schleife nicht beenden
            log.exception("Periodische Aufgabe fehlgeschlagen")
        await asyncio.sleep(INTERVAL_SECONDS)
```

```python
from sqlalchemy import engine_from_config, pool

from app import models  # noqa: F401 - registriert die Tabellen an Base.metadata

if config.config_file_name is not None:
    fileConfig(config.config_file_name)

config.set_main_option("sqlalchemy.url", get_settings().database_url)

target_metadata = Base.metadata


def run_migrations_offline() -> None:
    context.configure(
        url=config.get_main_option("sqlalchemy.url"),
        target_metadata=target_metadata,
        literal_binds=True,
        dialect_opts={"paramstyle": "named"},
    )
    with context.begin_transaction():
        context.run_migrations()


def run_migrations_online() -> None:
    connectable = engine_from_config(
        config.get_section(config.config_ini_section, {}),
        prefix="sqlalchemy.",
        poolclass=pool.NullPool,
    )
    with connectable.connect() as connection:
        context.configure(connection=connection, target_metadata=target_metadata)
        with context.begin_transaction():
            context.run_migrations()


if context.is_offline_mode():
    run_migrations_offline()
else:
    run_migrations_online()
```

`server/Dockerfile`:
```dockerfile
FROM python:3.12-slim

RUN apt-get update \
    && apt-get install -y --no-install-recommends curl tzdata \
    && rm -rf /var/lib/apt/lists/*

ENV PYTHONDONTWRITEBYTECODE=1 \
    PYTHONUNBUFFERED=1 \
    PIP_NO_CACHE_DIR=1

WORKDIR /srv/youtube-safe

COPY requirements.txt ./
RUN pip install --no-cache-dir -r requirements.txt

COPY alembic.ini ./
COPY docker-entrypoint.sh /usr/local/bin/docker-entrypoint.sh
RUN chmod +x /usr/local/bin/docker-entrypoint.sh
COPY app/ ./app/

RUN useradd --system --create-home --uid 1000 yts \
    && mkdir -p /srv/updates \
    && chown -R yts:yts /srv/youtube-safe /srv/updates
USER yts

EXPOSE 8080

ENTRYPOINT ["/usr/local/bin/docker-entrypoint.sh"]
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8080", "--proxy-headers", "--forwarded-allow-ips", "*"]
```

`server/docker-entrypoint.sh`:
```bash
#!/usr/bin/env bash
#
# Migrationen einspielen, ersten Elternteil anlegen, dann die Anwendung. Beides idempotent.

set -Eeuo pipefail

echo "[youtube-safe] Migrationen ..."
alembic upgrade head

echo "[youtube-safe] Erster Elternteil ..."
python -m app.bootstrap

echo "[youtube-safe] Start."
exec "$@"
```

`deploy/docker-compose.yml`:
```yaml
# youtube-safe: Server, Datenbank, Push.
# Start:  docker compose --env-file .env up -d --build
services:
  app:
    build: ../server
    restart: unless-stopped
    env_file: .env
    environment:
      DB_HOST: db
      NTFY_URL: http://ntfy
      YTS_UPDATES_DIR: /srv/updates
    volumes:
      - ./updates:/srv/updates:ro
    depends_on:
      db:
        condition: service_healthy
    ports:
      - "127.0.0.1:${YTS_APP_PORT:-8090}:8080"
    healthcheck:
      test: ["CMD", "curl", "-fsS", "http://localhost:8080/health"]
      interval: 30s
      timeout: 5s
      retries: 3

  db:
    image: mariadb:11.4
    restart: unless-stopped
    environment:
      MARIADB_DATABASE: ${MARIADB_DATABASE:?MARIADB_DATABASE fehlt}
      MARIADB_USER: ${MARIADB_USER:?MARIADB_USER fehlt}
      MARIADB_PASSWORD: ${MARIADB_PASSWORD:?MARIADB_PASSWORD fehlt}
      MARIADB_ROOT_PASSWORD: ${MARIADB_ROOT_PASSWORD:?MARIADB_ROOT_PASSWORD fehlt}
    volumes:
      - db-data:/var/lib/mysql
    healthcheck:
      test: ["CMD", "healthcheck.sh", "--connect", "--innodb_initialized"]
      interval: 10s
      timeout: 5s
      retries: 10

  ntfy:
    image: binwiederhier/ntfy:v2.11.0
    restart: unless-stopped
    command: serve
    environment:
      NTFY_BASE_URL: ${NTFY_PUBLIC_URL:?NTFY_PUBLIC_URL fehlt}
    volumes:
      - ./ntfy/server.yml:/etc/ntfy/server.yml:ro
      - ntfy-data:/var/lib/ntfy
    ports:
      - "127.0.0.1:${YTS_NTFY_PORT:-8091}:80"

volumes:
  db-data:
  ntfy-data:
```

`deploy/README.md`:
````markdown
# Deployment

1. `cp .env.example .env`, Werte füllen (Passwörter: `openssl rand -base64 24`).
2. `mkdir -p updates && docker compose --env-file .env up -d --build`
3. ntfy-Benutzer für den Server anlegen und Token erzeugen:
   ```bash
   docker compose exec ntfy ntfy user add --role=admin yts-server
   docker compose exec ntfy ntfy token add yts-server
   ```
   Token in `.env` als `NTFY_TOKEN` eintragen, dann `docker compose up -d app`.
4. NPM: `tube.isoletta.me` → `127.0.0.1:8090`, `push.tube.isoletta.me` → `127.0.0.1:8091`
   (Websockets an), jeweils mit Let's Encrypt.
5. Prüfen: `curl -fsS https://tube.isoletta.me/health` → `{"status":"ok"}`
6. Backup: `docker compose exec db mariadb-dump -u root -p"$MARIADB_ROOT_PASSWORD" youtube_safe > backup.sql`
````
